6ブロックウィザード（配布用アプリ版）

■ 中身
index.html             アプリ本体（これ1つでも動きます）
manifest.webmanifest   ホーム画面に追加するための設定
sw.js                  オフラインでも開けるようにする仕組み
icon-*.png / apple-touch-icon.png   アプリのアイコン

■ 使い方1：PCでそのまま開く（いちばん簡単）
index.html をダブルクリックすると、ブラウザで開いて動きます。
メールやチャットで index.html だけを送っても使えます。

■ 使い方2：スマホのホーム画面にアプリとして置く
1. このフォルダの中身をすべて、無料の静的サイト公開サービス
   （GitHub Pages、Netlify、Cloudflare Pages など）にアップロードし、https のURLで公開する
2. そのURLを顧問先に送る
3. 顧問先はスマホのブラウザでURLを開き、
   iPhone：Safariの共有ボタン →「ホーム画面に追加」
   Android：Chromeのメニュー →「ホーム画面に追加」（または「アプリをインストール」）
一度開いたあとは、電波がなくても起動できます。

■ データの扱い
入力内容は、その端末のブラウザの中にだけ保存されます。
サーバーには送られず、あなた（配布者）からも見えません。
AIへの問い合わせは一切行いません。最後に作られるプロンプトを、
利用者が自分でChatGPTなどに貼り付けて使う仕組みです。

■ 更新するとき
index.html を差し替えたら、sw.js の1行目付近の CACHE = '6block-v1' を
'6block-v2' のように変えてからアップロードすると、利用者側でも確実に新しい版に切り替わります。
